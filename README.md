# Hillerset - strona wizytówkowa

Statyczna strona firmy Hillerset Roland Rafał Hiller (cyberbezpieczeństwo, ochrona danych, RODO, NIS2).

- HTML i CSS, bez JavaScriptu, bez zewnętrznych zasobów i bez ciasteczek.
- Polityka CSP w znaczniku meta, `no-referrer`.
- Zmiany w gałęzi `main` tylko przez pull request (zabezpieczenie gałęzi).
